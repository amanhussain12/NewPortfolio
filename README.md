## Getting Started

### Prerequisites

Make sure you have the following installed:

* Node.js 22.13.0 or newer
* npm

### Installation

Clone the repository:

```bash
git clone <repository-url>
cd meraj-creative-portfolio
```

Install the dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open http://localhost:3000 in your browser.

## Available Commands

```bash
npm run dev
```

Starts the local development server.

```bash
npm run build
```

Creates and validates the production build.

```bash
npm run start
```

Starts the production application.

```bash
npm run lint
```

Checks the project for code-quality issues.

```bash
npm test
```

Builds the project and runs the automated tests.
